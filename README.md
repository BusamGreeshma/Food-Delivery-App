# Food Delivery App

A modern, responsive food delivery web application built with React. The application provides an intuitive interface for exploring food items, filtering dishes by category, searching for meals, and managing a shopping cart.

The project focuses on creating a smooth food-ordering experience with reusable UI components, efficient state management, and interactive notifications.

## Live Demo

[Visit the Food Delivery App](https://food-delivery-app-swart-ten.vercel.app)

## Features

- **Food Category Filtering:** Browse dishes by categories such as breakfast, soups, and pizza.
- **Search Functionality:** Quickly find food items using the search feature.
- **Shopping Cart:** Add and remove items and increase or decrease quantities.
- **Automatic Price Calculation:** Calculate the subtotal, taxes, and delivery fee.
- **Interactive Cart Panel:** View and manage selected items through a sliding cart interface.
- **Toast Notifications:** Receive feedback when performing actions such as adding items or placing an order.
- **Responsive Design:** Use the application on desktop, tablet, and mobile screens.
- **State Management:** Manage cart and application state using Redux Toolkit and Context API.
- **Reusable Components:** Organize the interface into maintainable and reusable React components.

## Technology Stack

- **Frontend:** React.js
- **Programming Language:** JavaScript
- **State Management:** Redux Toolkit and Context API
- **Styling:** Tailwind CSS
- **Notifications:** React Hot Toast
- **Deployment:** Vercel

## How It Works

1. Users open the application and browse the available food items.
2. They filter dishes by category or search for specific items.
3. Selected dishes are added to the shopping cart.
4. Users modify item quantities or remove products.
5. The cart updates the subtotal, applicable taxes, and delivery fee.
6. Interactive notifications provide feedback for supported user actions.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/BusamGreeshma/Food-Delivery-App.git
cd Food-Delivery-App
```

### 2. Navigate to the application directory

```bash
cd "Food Delivery App"
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

Check the `scripts` section of `package.json` and run the appropriate command. For a Vite-based React application, use:

```bash
npm run dev
```

If the project uses a different build tool, follow the script defined in `package.json`.

### 5. Open the application

Open the local development URL shown in the terminal.
